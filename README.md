# 🔐 Sistema de Autenticação em Python

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## Sobre o projeto

Projeto desenvolvido para praticar conceitos de desenvolvimento e segurança em Python, evoluindo gradualmente por diferentes versões.

## Objetivos

- Praticar programação em Python
- Desenvolver um sistema de autenticação
- Trabalhar com armazenamento e gerenciamento de usuários
- Aprender conceitos de segurança de aplicações
- Desenvolver uma API REST
- Aplicar novos conceitos de forma incremental a cada versão

## Evolução do projeto

### V1.0 — Cadastro e Login

- Cadastro de usuários
- Sistema de login
- Validação de credenciais
- Execução pelo terminal

### V2.0 — SQLite + bcrypt

- Persistência de usuários com SQLite

## Como executar

### Clonar o repositório

```bash
git clone https://github.com/leticiamagalhaes-ti/projeto-sistema-autenticacao.git
```

### Acessar o projeto

```bash
cd projeto-sistema-autenticacao
```

### Executar a V1

```bash
python v1_cadastro_login/v1.py
```

### Executar a V2

```bash
python v2_sqlite_bcrypt/v2.py
```
